# Gems of Cards

Production Next.js frontend connected to the existing Supabase backend.

## Setup
1. Copy `.env.example` to `.env.local`.
2. Add the Supabase publishable key.
3. Run `npm install` then `npm run dev`.
4. Create your admin email/password user in Supabase Auth.

## Includes
Homepage, collection search/filtering, METALLIC GEMS, Featured Gems, individual card URLs, admin login, cloud image upload, permanent database storage and card deletion.

For deployment, push this folder to GitHub and import it into a Next.js host, then add the same environment variables.
